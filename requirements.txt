# Embeddings: fastembed runs on onnxruntime (CPU), not PyTorch. This is a
# deliberate choice over sentence-transformers/transformers/torch, which
# pull in ~2GB of CUDA wheels and use several hundred MB of RAM at runtime
# even on a CPU-only box - that was OOM-killing this app on Render's free
# tier (512MB RAM limit). fastembed uses the same
# sentence-transformers/all-MiniLM-L6-v2 model (same 384-dim vectors, so
# the bundled FAISS index in app/rag/product_index/ stays compatible)
# without the PyTorch overhead.
